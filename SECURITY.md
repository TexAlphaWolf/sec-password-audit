# Security policy

If you find a vulnerability (for example a way to make pwaudit print or store a password, send more than the 5-character hash prefix, report a failed lookup as "not found", or crash or hang on a crafted CSV or breach file), please use GitHub's **private vulnerability reporting** (Security tab, "Report a vulnerability") instead of a public issue. You will get an answer within a few days.

Supported: the latest release.

How the project handles passwords is in [docs/security.md](docs/security.md).
