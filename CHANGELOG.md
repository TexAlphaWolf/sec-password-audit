# Changelog

## 1.0.0

First release: pattern-aware strength estimator (dictionary with capitals, leetspeak and reversal, keyboard walks, sequences, repeats, dates, user context), four-scenario crack-time table, Have I Been Pwned lookup by k-anonymity (online with padding, or offline by binary search over the ordered-by-hash file), `check` for one password and `audit` for password-manager CSV exports (weak, reused, breached, empty, short; text, Markdown and JSON reports), calibration tool, live API check, Docker image.
